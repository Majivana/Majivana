A student work-contribution and evidence-management application designed to connect work entries, evidence submissions, supervisor reviews, and verification history. The project includes a Java/Spring Boot backend and a React/TypeScript browser frontend.

**Focus:** REST APIs · validation · authentication and permissions · evidence workflow · testing · Docker · CI/CD  
**Status:** Local development is the verified runtime. PostgreSQL compatibility and AWS deployment remain in progress; see the repository documentation for current limitations.

### 🔹 [Solar Fleet Management MVP](https://github.com/Majivana/Solar-Fleet)
An operator-focused solar fleet management application with site and project workspaces, inverter lifecycle actions, alarm handling, activity history, cost and savings estimates, and exportable reports.

**Focus:** Java · Spring Boot · PostgreSQL · Flyway · Docker · API design · application security  
**Status:** Manufacturer integrations are not configured. Synthetic demo data is identified as demo data in the project.

### 🔹 [Robot Worlds — Brownfields Project](https://github.com/Majivana/brownfields_robot_worlds_)
A collaborative Java client-server simulation where robot clients interact with a shared 2D world. The project explores object-oriented design, TCP socket communication, JSON protocol messaging, REST endpoints, persistence, and automated build/test workflows.

**Focus:** Java · Maven · networking · JSON · REST · testing · Docker · GitLab CI

### 🔹 [Ngqamakwe Luxury Guest House](https://github.com/Majivana/Nqamakwe-Luxury-Guesthouse-and-Conference-Centre)
A full-stack hospitality application with a Node.js/Express API, SQLite persistence, booking and inventory workflows, staff operations, guest notifications, and a hosted-payment integration boundary.

**Focus:** JavaScript · Node.js · Express · SQLite · API integration · role-based workflows  
**Status:** Payment, social sign-in, and email features require appropriate provider credentials and deployment configuration. See the repository README for setup details.
